ترتیب فعال‌سازی

  1. در Cloudflare یک پایگاه دادهٔ D1 و Worker بسازید.
  2. در GitHub یک OAuth App بسازید؛ نشانی callback را روی /auth/callback در Worker بگذارید.
  3. شناسه‌های مدیر و اسرار را در Worker تنظیم و مهاجرت D1 را اجرا کنید.
  4. نشانی Worker را در config.js بگذارید و GitHub Pages را فعال کنید.
