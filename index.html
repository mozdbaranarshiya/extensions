اطلاعات ورود در دسترس نیست.

محدودهٔ عملکرد

ورود تنها از مسیر /accupdator/validate و با توکن مدیریتی معتبر که با @ آغاز می‌شود انجام می‌گیرد. توکن عادی هرگز به API مدیریتی ارسال نمی‌شود.

عملیات مبتنی بر API مدیر: مشاهده حساب، ایجاد/حذف/تغییر تاریخ مشترکان، وضعیت و بروزرسانی کوکی‌ها، و خواندن فهرست پروکسی‌ها.

قابلیت‌هایی که به مجوز chrome.proxy، chrome.cookies، تب مرورگر یا تزریق محتوا نیاز دارند (مثل فعال‌سازی VPN/پروکسی، دریافت خودکار کوکی و ورود خودکار سرویس‌ها) در GitHub Pages قابل اجرای مستقیم نیستند. برای آن‌ها همچنان باید اکستنشن را اجرا کنید.

مقدار توکن در URL، localStorage، sessionStorage یا مخزن GitHub نگهداری نمی‌شود؛ پس از بارگذاری مجدد صفحه نیاز به ورود دوباره است.
